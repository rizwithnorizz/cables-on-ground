# Cables on Ground

A cable and drum reservation system built for fast-paced field operations.

## Operations

* Cable inventory management
* Drum tracking with current and initial lengths
* Real-time reservation system
* Partial reservation handling
* Cable cutting workflow management
* Open and reserved drum monitoring
* Daily reservation status automation
* Excel export support for reports and logs
* Dashboard-based inventory overview
* User and operational activity tracking
* Search and filtering for drums, cables, and reservations
* Automated inventory status updates
* Warehouse and field operation support

## Stack

* Next.js
* TypeScript
* Supabase

## Why this project exists

Most inventory systems are bloated, slow, and painful to use on-site. This project focuses on speed, clarity, and operational efficiency for cable management.
