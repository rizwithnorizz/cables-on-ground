# 🔌 Cables on Ground

A modern, full-stack cable inventory management system built to streamline operations, track stock, and optimize cutting workflows.

## ✨ Features

🎯 **Smart Dashboard** - Get a complete overview of inventory, recent activities, and key metrics at a glance

📦 **Cable Inventory Management** - Organize and track all your cables with detailed specifications (brand, type, size)

✂️ **Cutting Operations** - Execute precision cutting orders with real-time tracking and print-ready reports

🔗 **Reservation System** - Reserve cables for upcoming projects and manage availability seamlessly

💰 **Transaction Tracking** - Monitor all stock movements with detailed transaction history and batch exports

🔐 **Secure Authentication** - Role-based access control with admin privileges for sensitive operations

📜 **Certificate Management** - Download and manage test certificates in bulk with automated file organization

⚡ **Real-time Sync** - Supabase integration for instant data synchronization across all operations

## 🚀 Tech Stack

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Supabase
- **Database**: PostgreSQL (via Supabase)
- **Authentication**: Supabase Auth with SSR support

## 🎯 Use Cases

Perfect for:
- Cable distributors and manufacturers
- Construction and electrical companies
- Inventory management teams
- Operations that require precise cutting orders and stock tracking

## 📋 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up your Supabase project and environment variables
4. Run the development server: `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000)
